# @dsh-selfuse/skill-router

[English](README.md) | 中文

## 概述

这个旧插件向 Cordis 作用域内每个 Agent 的系统提示词插入固定的中文技能路由段。它没有工具，也不会安装所列技能。启用这一额外提示段前，应检查当前官方技能目录和用户实际选择的技能。

## 目录

- 配置
- 模型体验
- 已知限制与待办
- 开发备注

## 配置

布尔型 `enabled` 决定 `apply` 是否在 order 110 注册 `tool:dsh-skill-router` 段。关闭插件后，组成更新会移除该段。

## 模型体验

### 固定技能路由段

#### 模型看到什么

启用后，作用域内每个 Agent 都收到固定的中文任务分类与技能名称指南，作为系统提示词段。插件不会检查每个被列出的技能是否实际已安装。

#### Token 影响

每次组装请求时，整个固定段都会增加系统提示词 token；不增加工具 schema 或结果 token。

#### KV Cache 影响

启用期间该段稳定，未变化的前缀可被供应商缓存复用。修改插件文本或切换开关会改变后续请求的前缀。

## 已知限制与待办

- 写死的技能数量和名称可能已与当前安装目录不符。
- 其中的规定流程可能与用户指令或当前官方技能指导冲突；不能用它替代对实际技能的检查。

### 开发备注

启用前应对照活跃技能清单检查固定段。源码位于 `src/index.ts`；旧构建与注入说明是开发路径，不是运行时验证。
