# @deepseek-ai/dsh-file-changes

[English](README.md) | 中文

## 概述

这个旧模块把已记录的工具结果 diff 元数据投影给浏览器文件视图。当前工作区只有清单和构建产物。它本身既不还原文件，也不增加模型输入。

## 目录

- 兼容用途
- 已知限制与待办
- 开发备注

## 兼容用途

安装对应浏览器模块后，旧桌面文件视图会消费该投影。

## 已知限制与待办

- 缺少源码，无法在此独立修改投影行为以适配新版 Session 格式。
- 迁移前必须用当前记录的 Session 事件做重放测试。

### 开发备注

官方 Session 投影提供所需文件更改数据时应优先使用官方方案。
