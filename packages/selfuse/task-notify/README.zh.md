# @dsh-selfuse/task-notify

[English](README.md) | 中文

## 概述

此配套模块监听主会话回合完成事件，并请求向用户显示 Windows 通知。排除子代理会话和被中断的回合。通知失败不会中断 Host。

## 目录

- 兼容用途
- 已知限制与待办
- 开发备注

## 兼容用途

通知把任务完成情况报告给用户，不创建 Agent 指令或工具结果。带类型的源码重建 `lib/index.js`；事件测试不能证明 Windows 通知实际投递成功。会话退出时清除其标题缓存，插件卸载时撤回监听器并清空缓存。不发布 invariant 配套模块，因为此观察者没有需独立对账的持久状态。

## 已知限制与待办

- 候选分支尚未验证 Windows 通知权限和投递。
- 弹出通知不能证明远程浏览器收到了最终对话状态。

### 开发备注

仅在目标部署完成真实 Windows 通知冒烟后使用。
