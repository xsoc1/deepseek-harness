# @deepseek-ai/dsh-easy-setup

[English](README.md) | 中文

## 概述

此继承的桌面设置模块曾提供模型选择、`soul.md` 编辑以及从其他编码助手导入配置。当前工作区只有预构建产物。它不是当前 DSH 设置的首选途径。

## 目录

- 兼容用途
- 已知限制与待办
- 开发备注

## 兼容用途

包清单标明其设置页集成；任何导入操作都应由用户明确审阅。

## 已知限制与待办

- 缺少源码，不能在此审计导入行为及其对当前设置的兼容性。
- 未做可丢弃 profile 测试和确认备份前，不应对活跃 DSH 用户目录执行迁移。

### 开发备注

官方设置控件能完成同一任务时，应优先使用官方控件。
