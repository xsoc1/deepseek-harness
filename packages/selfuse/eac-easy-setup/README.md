# @deepseek-ai/dsh-easy-setup

English | [中文](README.zh.md)

## Summary

This inherited desktop settings module offered model selection, `soul.md` editing, and imports from other coding assistants. Only its prebuilt output is present in this checkout. It is not a preferred path for current DSH settings.

## Table of Contents

- Compatibility role
- Known Limitations and Deferred Work
- Dev Note

## Compatibility role

The package manifest identifies a settings-page integration; any import operation must be explicitly reviewed by the user.

## Known Limitations and Deferred Work

- Source is absent, so import behavior and compatibility with current settings cannot be audited here.
- Do not run a migration against the live DSH home without a verified backup and a disposable-profile trial.

### Dev Note

Prefer current official settings controls when they cover the same task.
