# @deepseek-ai/dsh-client-file-changes

[English](README.md) | 中文

## 概述

此继承的浏览器模块展示会话文件更改，并为旧桌面集成提供还原控件。当前工作区只有构建产物，没有源码。重新启用前应评估当前官方桌面和文件更改功能。

## 目录

- 兼容用途
- 已知限制与待办
- 开发备注

## 兼容用途

浏览器视图读取文件更改投影；还原依赖桌面壳桥。

## 已知限制与待办

- 缺少源码，无法在此安全修改其行为以适配当前客户端 API。
- 启用前应在可丢弃工作区测试还原操作。

### 开发备注

除非经验证的活跃 profile 确实需要旧视图，否则保持禁用。
