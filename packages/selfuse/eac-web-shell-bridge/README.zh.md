# @deepseek-ai/dsh-web-shell-bridge

[English](README.md) | 中文

## 概述

此继承的桥接模块曾为纯 Web 环境补齐桌面壳的文件还原和系统打开操作。当前工作区只有构建产物。未检查当前官方桌面与浏览器 API 之前不应启用。

## 目录

- 兼容用途
- 已知限制与待办
- 开发备注

## 兼容用途

桥接模块向旧浏览器集成提供由用户触发的壳功能；它不是 Agent 工具。

## 已知限制与待办

- 缺少源码，不能在此审计还原和打开操作的范围及授权方式。
- 当前官方桌面壳可能已经提供同类功能，重复桥接可能导致行为冲突。

### 开发备注

保持禁用，直至明确的集成测试证实仍需要这个桥接模块。
