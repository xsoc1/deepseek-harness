# @deepseek-ai/dsh-task-notify

[English](README.md) | 中文

## 概述

此继承的 Web 配套模块监听回合完成事件，并请求向用户显示 Windows 通知。清单说明会排除子代理会话。当前工作区只有构建产物，需要另行测试新版运行行为。

## 目录

- 兼容用途
- 已知限制与待办
- 开发备注

## 兼容用途

通知把任务完成情况报告给用户，不创建 Agent 指令或工具结果。

## 已知限制与待办

- 缺少源码；候选分支尚未验证 Windows 通知权限和投递。
- 弹出通知不能证明远程浏览器收到了最终对话状态。

### 开发备注

仅在目标部署完成真实 Windows 通知冒烟后使用。
