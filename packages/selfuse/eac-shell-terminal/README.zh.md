# @deepseek-ai/dsh-shell-terminal

[English](README.md) | 中文

## 概述

此继承的桌面模块在对话旁提供人工操作终端。清单描述的是 SSE 流，不是 PTY。当前只有构建产物，不能把它当作可维护的当前官方终端替代品。

## 目录

- 兼容用途
- 已知限制与待办
- 开发备注

## 兼容用途

终端是桌面用户控件，不是 Agent shell 工具。

## 已知限制与待办

- 缺少源码；本工作区尚未审计命令隔离及其与当前客户端的兼容性。
- 它不是 PTY，不应假定支持完整终端行为。

### 开发备注

除非经过验证的旧工作流需要此模块，否则应优先使用当前官方终端。
