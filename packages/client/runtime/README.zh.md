# @deepseek-ai/dsh-client-runtime

[English](README.md) | 中文

## 概述

本包为旧版 selfuse 插件保留 0.1.2 之前的浏览器运行时 API。当前工作区只有构建后的 `lib` 产物和清单，没有可维护源码。新代码应使用当前官方客户端包。

## 目录

- 兼容用途
- 已知限制与待办
- 开发备注

## 兼容用途

清单导出根入口、浏览器客户端和 invariant 入口。迁移期间，现有旧版消费者仍可解析这些名称。

## 已知限制与待办

- 当前工作区没有源码或构建配方，不能仅凭本包确定其上游 API 兼容性。
- 新插件不应继续优先依赖此兼容产物。

### 开发备注

仅在经验证的旧版消费者仍需要它时保留；消费者迁移至当前官方客户端包后再移除。
